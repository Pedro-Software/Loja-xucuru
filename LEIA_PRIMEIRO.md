# Kit de preparação — Loja Xukuru

Este ZIP **não contém o site pronto**. Ele contém briefing convertido, instruções permanentes para o Codex e 8 prompts para gerar o MVP por etapas.

## Instalar na pasta que você já criou
1. Abra `C:\projetos\lojaxucuru` no Explorador do Windows.
2. Extraia o conteúdo do ZIP **diretamente dentro dessa pasta**, mantendo as pastas internas (`docs/`).
3. Confira se existem `AGENTS.md`, `PROMPTS_CODEX.md` e `docs/BRIEFING.md` na raiz esperada. Não deixe tudo em uma subpasta `kit_lojaxucuru`.
4. Abra VS Code com **Arquivo > Abrir Pasta > C:\projetos\lojaxucuru**.
5. Abra `PROMPTS_CODEX.md`, envie o Prompt 1 ao Codex e revise o resultado antes de avançar.

O briefing DOCX original enviado já está em `docs/briefing-original.docx`.

Importante: não disponibilize a loja para pagamentos reais até conectar gateway/frete, validar dados dos produtos e revisar condições comerciais com quem participa do projeto.
